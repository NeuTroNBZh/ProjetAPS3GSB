# Glossaire

| Terme | Définition |
|---|---|
| **GSB** | Galaxy Swiss Bourdin, laboratoire pharmaceutique issu de fusions (Swiss, Bourdin, Galaxy). |
| **CR / Rapport de visite** | Compte-rendu d'une visite d'un visiteur chez un praticien. |
| **Visiteur médical** | Commercial qui présente les produits du labo aux praticiens. |
| **Délégué régional** | Visiteur (3/4 temps) qui coordonne les visiteurs d'une région. |
| **Responsable de secteur** | Encadre les régions d'un secteur ; objectifs, budgets, évaluations. |
| **Collaborateur** | Terme actuel désignant indifféremment visiteur, délégué, responsable. |
| **Praticien** | Médecin généraliste, spécialiste, service hospitalier, pharmacien, infirmier… |
| **Portefeuille** | Ensemble des praticiens suivis par un visiteur (un praticien = un seul visiteur). |
| **Remplaçant** | Praticien rencontré à la place du titulaire du cabinet. |
| **Coef. de notoriété** | Influence du praticien sur son entourage (donnée achetée). |
| **Coef. de prescription** | Reconnaissance du praticien comme référent dans sa spécialité (donnée achetée). |
| **Coef. de confiance** | Évaluation par le visiteur de la propension du praticien à prescrire les produits GSB plutôt que la concurrence. |
| **Périodicité** | Motif principal : revoir chaque praticien tous les 6 à 8 mois. |
| **Remontage** | Visite suite à une baisse de prescription signalée par la hiérarchie. |
| **Dépôt légal** | Numéro identifiant un médicament. |
| **Échantillon** | Médicament offert au praticien ; suivi obligatoire à l'unité près. |
