# GSB-CR — Documentation utilisateur

GSB-CR est l'application de bureau des collaborateurs de Galaxy Swiss Bourdin pour saisir et suivre les **comptes-rendus de visite** (CR) des visiteurs médicaux. Cette documentation présente le mode opératoire de chaque module (version 1.1.0).

## Quel guide lire ?

Chaque collaborateur voit uniquement les modules de son profil.

| Vous êtes… | Modules | À lire |
|---|---|---|
| Visiteur médical | Mes comptes-rendus, Praticiens, Médicaments, Mon activité, Messagerie | [Démarrer](01-demarrer.md), [Module Visiteur](02-visiteur.md), [Messagerie](05-messagerie.md) |
| Délégué régional | Ceux du visiteur + Ma région, Échantillons | Les précédents + [Module Délégué](03-delegue.md) |
| Responsable de secteur | Mon secteur, Échantillons (consultation), Praticiens, Médicaments, Messagerie | [Démarrer](01-demarrer.md), [Module Responsable](04-responsable.md), [Messagerie](05-messagerie.md) |
| Administrateur | Administration, Praticiens, Médicaments, Messagerie | [Démarrer](01-demarrer.md), [Module Administration](06-administration.md) |

En cas de difficulté : [Questions fréquentes et messages d'erreur](07-questions-frequentes.md).

## Conventions

- Les libellés entre guillemets (« Valider le compte-rendu ») sont ceux affichés à l'écran.
- Un astérisque `*` à côté d'un champ indique une saisie obligatoire.
- Le bouton principal de chaque fenêtre est en bleu plein ; « Fermer » ou « Annuler » ne change rien.
- Les captures d'écran proviennent du jeu d'essai (données fictives).
